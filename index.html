Ba cách nhúng CSS vào HTML

CÁCH 1 – INLINE STYLE

Inline Style

Inline Style được viết trực tiếp vào thuộc tính style="" của từng thẻ HTML. Ưu điểm là áp dụng ngay lập tức cho phần tử đó, nhưng khó bảo trì khi trang web có nhiều phần tử vì phải sửa từng thẻ một.

→ Màu tiêu đề: color: #27ae60  |  Màu đoạn văn: color: #145a32 (đều viết bằng Inline Style)

CÁCH 2 – INTERNAL STYLE

Internal Style

Internal Style được viết trong thẻ <style> đặt bên trong thẻ <head> của file HTML. Ưu điểm là quản lý CSS tập trung trong một file, phù hợp với các trang đơn lẻ, nhỏ gọn. Nhược điểm là không tái sử dụng được giữa nhiều file HTML khác nhau.

→ Màu tiêu đề: color: #e67e22  |  Màu đoạn văn: color: #784212 (đều viết bằng Internal Style trong <head>)

CÁCH 3 – EXTERNAL STYLE

External Style

External Style được viết trong một file .css riêng biệt (ví dụ: style.css), sau đó liên kết vào HTML bằng thẻ <link rel="stylesheet" href="style.css"> đặt trong <head>. Đây là cách được khuyến nghị nhất vì CSS có thể tái sử dụng cho nhiều trang, dễ bảo trì và tách biệt hoàn toàn nội dung với định dạng.

→ Màu tiêu đề và đoạn văn được định nghĩa trong file style.css (External Style)
